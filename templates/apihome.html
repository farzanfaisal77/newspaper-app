Available API Endpoints

1. Documentation & Schemas

  • Swagger UI Sandbox - Test endpoints interactively.
    URL: /apis/schema/swagger-ui/
  • ReDoc Documentation - Read-only API reference.
    URL: /apis/schema/redoc/
  • OpenAPI Schema - Raw OpenAPI definition file.
    URL: /apis/schema/

2. Authentication & Accounts

  • User Login (POST) - Sign in with credentials.
    URL: /apis/dj-rest-auth/login/
  • User Registration (POST) - Create a new user account.
    URL: /apis/dj-rest-auth/registration/
  • User Logout (POST) - End session.
    URL: /apis/dj-rest-auth/logout/
  • User Details (GET, PUT, PATCH) - Get/update current user.
    URL: /apis/dj-rest-auth/user/
  • Password Change (POST) - Change user password.
    URL: /apis/dj-rest-auth/password/change/
  • Password Reset (POST) - Request password reset mail.
    URL: /apis/dj-rest-auth/password/reset/
  • Password Reset Confirm (POST) - Confirm password reset.
    URL: /apis/dj-rest-auth/password/reset/confirm/

3. Core Resources

  • Articles List & Create (GET, POST) - List articles or create a new article.
    URL: /apis/articles/
  • Article Details (GET, PUT, PATCH, DELETE) - Retrieve or update/delete an article.
    URL: /apis/articles/<article_id>/
  • Comments List & Create (GET, POST) - List/write comments on a post.
    URL: /apis/articles/<article_id>/comments/
  • Comment Details (GET, PUT, PATCH, DELETE) - Retrieve or update/delete a comment.
    URL: /apis/articles/<article_id>/comments/<comment_id>/
  • Users List (GET, POST) - Manage users (Admin only).
    URL: /apis/users/
  • User Details (GET, PUT, PATCH, DELETE) - Manage specific user details (Admin only).
    URL: /apis/users/<user_id>/
